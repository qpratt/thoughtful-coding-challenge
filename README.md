# BoxBot Box Sorter

## Getting Started
### Prerequisites
- Terminal access
- Node v20
- (approving `watchman` may be necessary on mac when running tests)

### Run the app
1. Using a terminal of your choice, clone this repository.
2. In the project directory, run `yarn` to install Jest, the only project dependency. This is useful when running the tests.
3. This Node app uses command arguments for inputs. Run the app like so, `node BoxBot.js 100 100 100 5`

### Run tests
1. Ensure you've already ran `yarn` to install Jest
2. Run `yarn test`
